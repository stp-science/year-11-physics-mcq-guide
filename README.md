# Year 11 Physics MCQ Guide

Student guidance website for the 2025 Year 11 Physics mock examinations.

The site has a separate page for:
- Mechanics
- Waves
- Particle Physics

Each question gives the correct option, the reasoning needed to reach it, and an explanation of why the other choices are incorrect.

## GitHub Pages

The website is designed to be published directly from the repository root on the `main` branch.
